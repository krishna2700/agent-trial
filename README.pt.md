# Agent Trial

## Descrição

Bem-vindo ao **Agent Trial**! Este é um projeto de demonstração simples que contém arquivos básicos de JavaScript e HTML para fins de teste e aprendizado.

## Conteúdo do Projeto

| Arquivo | Descrição |
|---------|-----------|
| `hello.js` | Script Node.js que imprime uma mensagem de saudação no console |
| `index.html` | Página HTML básica para visualização no navegador |
| `README.md` | Documentação do projeto em espanhol |
| `README.pt.md` | Documentação do projeto em português (este arquivo) |

## Requisitos Prévios

Antes de começar, certifique-se de ter instalado em sua máquina:

- [Node.js](https://nodejs.org/) (versão 14 ou superior)
- Um navegador web moderno (Chrome, Firefox, Edge, Safari)
- [Git](https://git-scm.com/)

## Instalação

Siga os passos abaixo para configurar o projeto localmente:

1. Clone o repositório:
   ```bash
   git clone https://github.com/krishna2700/agent-trial.git
   ```

2. Acesse o diretório do projeto:
   ```bash
   cd agent-trial
   ```

3. Pronto! Não há dependências adicionais a instalar.

## Uso

### Executar o script JavaScript

Para rodar o arquivo `hello.js` com Node.js:

```bash
node hello.js
```

Você verá a mensagem de saudação impressa no terminal.

### Visualizar a página HTML

Para abrir o arquivo `index.html` no navegador, você pode:

- Abrir diretamente clicando duas vezes no arquivo, ou
- Servir localmente com Python:

```bash
# Python 3
python3 -m http.server 8080
```

Em seguida, acesse `http://localhost:8080` no seu navegador.
