# Projeto Agent Trial

## Descrição

Este projeto é um ambiente de testes para agentes automatizados. Ele contém arquivos de exemplo que demonstram as capacidades básicas do sistema.

## Estrutura do projeto

```
.
├── README.md       # Arquivo de documentação principal
├── hello.js        # Script JavaScript de demonstração
└── index.html      # Página HTML principal
```

## Pré-requisitos

- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- Um navegador web moderno

## Instalação

Clone o repositório na sua máquina local:

```bash
git clone https://github.com/krishna2700/agent-trial.git
cd agent-trial
```

## Utilização

### Executar o script JavaScript

```bash
node hello.js
```

### Abrir a página HTML

Abra o arquivo `index.html` diretamente no seu navegador, ou inicie um servidor local:

```bash
python3 -m http.server 3456
```

Em seguida, acesse `http://localhost:3456` no seu navegador.
