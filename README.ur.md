# React کا تعارف (اردو میں)

## React کیا ہے؟

React ایک JavaScript لائبریری ہے جو **ماڈیولر**، **تیز** اور **قابلِ انتظام** انداز میں یوزر انٹرفیس (UI) بنانے کے لیے تیار کی گئی ہے۔ اسے بنیادی طور پر کمپوننٹس پر مبنی جدید ویب ایپلیکیشنز بنانے کے لیے استعمال کیا جاتا ہے۔

## React کیوں استعمال کریں؟

- **دوبارہ استعمال کے قابل کمپوننٹس**: انٹرفیس کو آزاد بلاکس میں تقسیم کریں۔
- **مؤثر رینڈرنگ**: React، Virtual DOM کی مدد سے DOM کو بہترین طریقے سے اپ ڈیٹ کرتا ہے۔
- **بھرپور ماحول**: ٹولز، لائبریریاں اور ایک بہت متحرک کمیونٹی۔
- **اچھی قابلیتِ انتظام**: واضح آرکیٹیکچر جو وقت کے ساتھ بڑھتی ہوئی ایپلیکیشنز کے لیے موزوں ہے۔

## بنیادی تصورات

### 1) کمپوننٹس

ایک کمپوننٹ ایک فنکشن (یا کلاس) ہوتا ہے جو یوزر انٹرفیس واپس کرتا ہے۔

- **پیرنٹ کمپوننٹ**: دوسرے کمپوننٹس کو اپنے اندر رکھتا ہے۔
- **چائلڈ کمپوننٹ**: پیرنٹ سے ڈیٹا وصول کرتا ہے۔

### 2) JSX

JSX ایک ایسی سنٹیکس ہے جو JavaScript کے اندر HTML جیسی نظر آتی ہے۔

مثال:

```jsx
const element = <h1>ہیلو React</h1>;
```

### 3) Props

**Props** وہ ڈیٹا ہے جو پیرنٹ کمپوننٹ سے چائلڈ کمپوننٹ کو بھیجا جاتا ہے۔
یہ چائلڈ کمپوننٹ کے اندر صرف پڑھنے کے قابل ہوتا ہے۔

### 4) State (حالت)

**State** ایک کمپوننٹ کا اندرونی ڈیٹا ہے جو وقت کے ساتھ تبدیل ہو سکتا ہے (صارف کی تعامل، API کا جواب، وغیرہ)۔

### 5) یک طرفہ ڈیٹا فلو

React میں ڈیٹا بنیادی طور پر پیرنٹ سے چائلڈ کی طرف بہتا ہے۔ یہ ماڈل ایپلیکیشن کے رویے کو زیادہ قابلِ پیشین گوئی بناتا ہے۔

## ضروری Hooks

### useState

فنکشنل کمپوننٹ میں مقامی حالت (state) کا انتظام کرنے کی اجازت دیتا ہے۔

### useEffect

رینڈرنگ کے بعد ضمنی اثرات (API کالز، سبسکرپشنز، ٹائمرز، وغیرہ) چلانے کی اجازت دیتا ہے۔

## ایک چھوٹی مثال

```jsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>گنتی: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        بڑھائیں
      </button>
    </div>
  );
}

export default Counter;
```

## شروع کرنے کے لیے بہترین طریقے

- کمپوننٹس کو چھوٹا اور قابلِ مطالعہ رکھیں۔
- کمپوننٹس اور متغیرات کے نام واضح رکھیں۔
- UI میں بھاری بزنس لاجک سے بچیں۔
- دہرائے جانے والے حصوں کو دوبارہ استعمال کریں۔
- جیسے جیسے پروجیکٹ بڑھے، ٹیسٹ شامل کرتے جائیں۔

## نتیجہ

React جدید اور مضبوط انٹرفیس بنانے کا ایک بہترین نقطہ آغاز ہے۔ کمپوننٹس، props، state اور hooks میں مہارت حاصل کر کے آپ قابلِ توسیع اور پیشہ ورانہ ایپلیکیشنز تیار کر سکتے ہیں۔
