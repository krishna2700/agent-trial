# Agent Trial

## Descripción

Este proyecto es un repositorio de prueba que contiene ejemplos básicos de JavaScript y HTML. Está diseñado para demostrar el uso de archivos simples en un entorno de desarrollo.

## Estructura del proyecto

```
agent-trial/
├── hello.js        # Script de ejemplo en JavaScript
├── index.html      # Página web de ejemplo en HTML
├── README.md       # Documentación en francés
└── README.es.md    # Documentación en español (este archivo)
```

## Requisitos previos

Antes de comenzar, asegúrese de tener instalado lo siguiente:

- [Node.js](https://nodejs.org/) (versión 14 o superior)
- Un navegador web moderno (Chrome, Firefox, Edge, Safari)

## Instalación

1. Clone este repositorio en su máquina local:

```bash
git clone https://github.com/krishna2700/agent-trial.git
```

2. Acceda al directorio del proyecto:

```bash
cd agent-trial
```

## Uso

### Ejecutar el script de JavaScript

Para ejecutar el archivo `hello.js` con Node.js:

```bash
node hello.js
```

### Abrir la página web

Para ver la página HTML, abra el archivo `index.html` directamente en su navegador:

```bash
# En sistemas Linux/Mac
open index.html

# O simplemente arrastre el archivo a su navegador
```
