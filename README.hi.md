# Agent Trial प्रोजेक्ट

## विवरण

यह प्रोजेक्ट स्वचालित एजेंट्स के परीक्षण के लिए एक वातावरण है। इसमें सिस्टम की बुनियादी क्षमताओं को प्रदर्शित करने के लिए उदाहरण फ़ाइलें शामिल हैं।

## प्रोजेक्ट संरचना

```
.
├── README.md       # मुख्य दस्तावेज़ीकरण फ़ाइल
├── hello.js        # डेमो JavaScript स्क्रिप्ट
└── index.html      # मुख्य HTML पृष्ठ
```

## पूर्वापेक्षाएँ

- [Node.js](https://nodejs.org/) (संस्करण 18 या उससे ऊपर)
- एक आधुनिक वेब ब्राउज़र

## स्थापना

रिपॉज़िटरी को अपनी स्थानीय मशीन पर क्लोन करें:

```bash
git clone https://github.com/krishna2700/agent-trial.git
cd agent-trial
```

## उपयोग

### JavaScript स्क्रिप्ट चलाएँ

```bash
node hello.js
```

### HTML पृष्ठ खोलें

`index.html` फ़ाइल को सीधे अपने ब्राउज़र में खोलें, या एक लोकल सर्वर शुरू करें:

```bash
python3 -m http.server 3456
```

फिर अपने ब्राउज़र में `http://localhost:3456` पर जाएँ।
