# एजेंट ट्रायल

## परियोजना का विवरण

यह एक सरल Node.js परियोजना है जो "Hello, World!" संदेश प्रदर्शित करती है। इस परियोजना का उद्देश्य बुनियादी JavaScript और Node.js कार्यक्षमता को प्रदर्शित करना है।

## फ़ाइलें

| फ़ाइल | विवरण |
|-------|-------|
| `hello.js` | मुख्य JavaScript फ़ाइल जो "Hello, World!" प्रिंट करती है |
| `README.hi.md` | हिंदी में परियोजना का दस्तावेज़ीकरण |

## आवश्यकताएँ

- [Node.js](https://nodejs.org/) संस्करण 14 या उससे अधिक
- npm (Node Package Manager)

## स्थापना

1. रिपॉजिटरी को क्लोन करें:

```bash
git clone https://github.com/krishna2700/agent-trial.git
```

2. परियोजना फ़ोल्डर में जाएँ:

```bash
cd agent-trial
```

## उपयोग

निम्न कमांड चलाएँ:

```bash
node hello.js
```

### अपेक्षित आउटपुट

```
Hello, World!
```

## परियोजना संरचना

```
agent-trial/
├── hello.js         # मुख्य कार्यक्रम फ़ाइल
└── README.hi.md     # हिंदी दस्तावेज़ीकरण
```

## योगदान

यदि आप इस परियोजना में योगदान देना चाहते हैं, तो कृपया निम्न चरणों का पालन करें:

1. इस रिपॉजिटरी को **Fork** करें
2. एक नई शाखा बनाएँ: `git checkout -b feature/नई-सुविधा`
3. अपने बदलाव करें और उन्हें commit करें: `git commit -m 'नई सुविधा जोड़ी'`
4. शाखा को push करें: `git push origin feature/नई-सुविधा`
5. एक **Pull Request** खोलें
