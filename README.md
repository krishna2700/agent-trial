# Proyecto Agent Trial

## Descripción

Este es un proyecto de prueba que contiene un archivo JavaScript básico y una página web simple.

## Archivos del Proyecto

- **hello.js** — Archivo JavaScript principal con funcionalidad básica de saludo.
- **index.html** — Página web principal del proyecto.
- **README.md** — Este archivo de documentación.

## Requisitos

- Node.js (versión 14 o superior)
- Un navegador web moderno para visualizar `index.html`

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/krishna2700/agent-trial.git
   ```

2. Accede al directorio del proyecto:
   ```bash
   cd agent-trial
   ```

## Uso

Para ejecutar el archivo JavaScript:

```bash
node hello.js
```

Para visualizar la página web, abre el archivo `index.html` en tu navegador preferido o usa un servidor local:

```bash
npx serve .
```
