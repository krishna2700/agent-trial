# agent-trial

## Descripción

**agent-trial** es una aplicación web que simula un editor de código moderno con una interfaz visual similar a Visual Studio Code. Incluye un explorador de archivos, pestañas de edición, resaltado de sintaxis, minimap, panel de terminal y barra de estado.

## Características

- 🗂️ **Explorador de archivos** — Árbol de archivos y carpetas con íconos por tipo de archivo
- 🖊️ **Editor de código** — Resaltado de sintaxis para JavaScript, JSX, CSS y más
- 📑 **Pestañas** — Soporte para múltiples archivos abiertos simultáneamente
- 🗺️ **Minimap** — Vista previa en miniatura del código
- 🔍 **Panel de esquema** — Navegación rápida por funciones y variables
- 💻 **Terminal integrada** — Panel inferior con salida de terminal simulada
- 📊 **Barra de estado** — Información del archivo, posición del cursor, codificación y más

## Tecnologías Utilizadas

- **HTML5** — Estructura y maquetación
- **CSS3** — Estilos, animaciones y diseño responsivo
- **JavaScript (Vanilla)** — Lógica de la interfaz sin dependencias externas

## Cómo Usar

1. Clona el repositorio:
   ```bash
   git clone <url-del-repositorio>
   ```

2. Abre el archivo `index.html` en tu navegador:
   ```bash
   open index.html
   ```

3. Explora los archivos en el panel lateral, haz clic en las pestañas para cambiar entre archivos y navega por el código.
