## Che cos'è Java

Java è un linguaggio di programmazione ad alto livello, orientato agli oggetti e indipendente dalla piattaforma. Il suo motto, "write once, run anywhere", indica che i programmi compilati in bytecode possono essere eseguiti su qualsiasi sistema che disponga della Java Virtual Machine (JVM).

### Concetti chiave

- **JVM**: Ambiente di esecuzione che permette ai programmi Java di funzionare su sistemi diversi.
- **OOP**: Java utilizza la programmazione orientata agli oggetti con classi e oggetti.
- **Portabilità**: Lo stesso codice può essere eseguito su Windows, macOS e Linux senza modifiche.
