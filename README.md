# Agent Trial

## Description

Ce projet est un dépôt de démonstration utilisé pour tester des agents automatisés. Il contient des fichiers exemples illustrant différentes fonctionnalités de base.

## Structure du projet

```
.
├── hello.js       # Script JavaScript d'exemple affichant un message de salutation
├── index.html     # Page HTML de démonstration
└── README.md      # Documentation du projet (ce fichier)
```

## Prérequis

- [Node.js](https://nodejs.org/) (version 14 ou supérieure)
- Un navigateur web moderne pour `index.html`

## Installation

Clonez ce dépôt sur votre machine locale :

```bash
git clone https://github.com/krishna2700/agent-trial.git
cd agent-trial
```

## Utilisation

### Exécuter le script JavaScript

```bash
node hello.js
```

### Ouvrir la page HTML

Ouvrez le fichier `index.html` directement dans votre navigateur, ou démarrez un serveur local :

```bash
npx serve .
```

## Contribution

Les contributions sont les bienvenues ! Pour proposer des modifications :

1. Créez une branche depuis `main` :
   ```bash
   git checkout -b feature/ma-fonctionnalite
   ```
2. Effectuez vos modifications et validez-les :
   ```bash
   git commit -m "Ajout de ma fonctionnalité"
   ```
3. Poussez la branche et ouvrez une Pull Request.
