# Proyecto Agent Trial

## Descripción

Este es un proyecto de prueba para el agente de automatización. Contiene archivos de ejemplo que demuestran el uso básico de JavaScript y HTML.

## Contenido del Proyecto

| Archivo | Descripción |
|---------|-------------|
| `hello.js` | Archivo JavaScript de ejemplo con un saludo básico |
| `index.html` | Página HTML principal del proyecto |
| `README.md` | Documentación del proyecto (este archivo) |

## Requisitos Previos

- [Node.js](https://nodejs.org/) v14 o superior
- Un navegador web moderno

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/krishna2700/agent-trial.git
   ```

2. Entra al directorio del proyecto:
   ```bash
   cd agent-trial
   ```

3. Instala las dependencias (si las hay):
   ```bash
   npm install
   ```

## Uso

Para ejecutar el archivo JavaScript:

```bash
node hello.js
```

Para ver la página HTML, abre `index.html` en tu navegador preferido.

## Estructura del Proyecto

```
agent-trial/
├── hello.js
├── index.html
└── README.md
```
