# Proyecto de Agente de Prueba

## Descripción

Este es un proyecto de prueba que sirve como plantilla para demostrar la funcionalidad básica de un agente. Contiene archivos de ejemplo para comenzar a trabajar rápidamente.

## Estructura del Proyecto

```
/
├── hello.js       # Archivo JavaScript de ejemplo con un saludo básico
├── index.html     # Página HTML principal del proyecto
└── README.md      # Este archivo de documentación
```

## Requisitos Previos

- [Node.js](https://nodejs.org/) (versión 14 o superior)
- Un navegador web moderno

## Instalación

1. Clona este repositorio en tu máquina local:

   ```bash
   git clone https://github.com/krishna2700/agent-trial.git
   ```

2. Navega al directorio del proyecto:

   ```bash
   cd agent-trial
   ```

## Uso

### Ejecutar el archivo JavaScript

```bash
node hello.js
```

### Abrir la página web

Abre el archivo `index.html` directamente en tu navegador o sírvelo con un servidor local:

```bash
npx serve .
```
