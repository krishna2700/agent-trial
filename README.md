# agent-trial

A minimal Node.js project used to trial and demonstrate agent-driven workflows.

## Overview

This repository contains a simple "Hello, World!" Node.js script. It serves as a sandbox for testing automated agents that create, modify, and manage files within a repository.

## Files

| File | Description |
|------|-------------|
| `hello.js` | Entry point — prints "Hello, World!" to the console |

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or higher recommended)

### Running the script

```bash
node hello.js
```

Expected output:

```
Hello, World!
```

## Purpose

This project is used as a trial repository for automated agent tasks such as:

- Creating and committing files
- Branching and pull request workflows
- Demonstrating end-to-end agent capabilities
